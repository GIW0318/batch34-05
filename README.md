# GSB Bugfix Task
## 题面
家园装修系统上线后，客服收到的都是权限和摆件问题。访客也能往别人家里塞家具，室友被房主授权以后却不能搬走自己摆的东西；上锁的房间只防了访客，室友照样能进去摆。家具摆放只判断了房间存不存在，没管家具宽度高度、越界和重叠，两块沙发能叠在同一个格子上；只能放客厅的家具出现在卧室里也不报错。舒适度算法和主题脱节，同套家具摆两件没有套装加成，家具主题和房间主题一致也没有加分，房间堆满以后分数无限涨。housing_decor.py 里的 HousingDecor 要重做授权、撤销、摆放、移除和舒适度计算。房间里记录宽高、主题和是否上锁，家具有占地宽高、舒适度、所属套装、适配主题和可用房型；坐标从零开始，家具必须完整落在房间内，也不能和同房间已有摆件重叠。房主可以授权室友或访客、可以撤销，室友只能摆放和移除，访客不能动手，锁定房间只有房主能进。摆放成功返回带编号的记录，移除按编号定位，编号不存在要报错。舒适度等于房间内家具舒适度之和，同套装达到两件加套装分，家具适配主题每件加一分，单房间按配置封顶后再汇总。查询结果要和内部记录完全隔离。授权角色只支持室友和访客，房主身份不能转授，撤销不存在的成员要报错。摆放和移除都要校验操作者是不是该房屋成员，非成员和访客一样被拒；同一件家具可以重复购买和摆放，每个摆件独立编号。舒适度按房间分别计算后再相加，空房间贡献零分。所有拒绝都要抛出 ValueError，成功摆放返回的编号在同一房屋内唯一。成员角色值用 owner、roommate、visitor。

## 运行方式
```bash
python -m pytest tests -q
```
