# GSB Bugfix Task
## 题面
农场玩法从测试服反馈的问题很集中。春天在地里种下番茄不报错，到了秋天才发现整块地都不长；温室地块和普通地块用了同一套季节判断，反季作物在温室里也被拒。生长推进按天结算，但雨天没有额外生长，干旱掉水和减产分开算，霜冻只扣水不扣健康，非耐寒作物冻了两天还活着；浇水接口可以无限加，水位没有上限。收获时提前收也能成功，当季作物的产量加成没进背包；市场价格只看基础价，反季和恶劣天气的溢价完全没体现，卖超库存会把金币刷成负数。farming_seasons.py 里的 FarmSeasons 要把地块、作物、季节轮换、天气结算、浇灌、收获入库和出售定价串起来。季节按春夏秋冬循环，每过配置的天数自动推进，作物只有在自己的季节列表里才能在普通地块播种，温室不受季节限制。每天推进时，当季作物和温室作物每次涨两点，反季作物只涨一点；雨天额外加一点并补水，干旱减一点，霜冻让生长回退一点，非耐寒作物同时掉一点健康，健康归零就从地块上清除，耐寒作物不受影响。水分上限三点，浇灌一次加一点。生长达到作物的成熟天数才能收获，当季产量加二、温室再加一，收完清空地块。售价按基础价乘反季和恶劣天气的倍率，反季、干旱、霜冻都按两倍计价；出售数量必须是正整数且不能超过库存。查询要能看到季节、天数、天气、每块地的作物、生长、水分、健康，以及金币和库存。季节推进在当天生长结算之前生效，跨季那天的作物按新季节计算；播种会扣掉种子费并重置水分和健康，未知地块、未知作物和已占用地块都要报错。季节值用 spring、summer、autumn、winter。

## 运行方式
```bash
python -m pytest tests -q
```
