# GSB Bugfix Task
## 题面
赛道计时和天气抓地的问题在赛季更新后集中爆发。车手注册时没有校验车辆和轮胎类型，随便传个字符串也能上场；发车以后可以重复发车，计时起点被覆盖。检查点只记了到达时间，没有校验顺序，跳过第二个点直接打第三个点也能过，时间还能倒退；两圈赛制没有按圈推进，跑完一圈就允许冲线。天气只影响显示，干地、雨天、暴风天的抓地惩罚完全没进成绩，光头胎在雨天和越野胎跑出一样的时间；中途切天气时，已经跑过的路段也被按新天气重算。racing_weather.py 里的 RacingWeather 要把注册、发车、检查点顺序、圈数、天气切换、冲线罚时和排行榜串起来。车手注册要带车辆和轮胎，两者都必须在目录里，同一个人不能重复注册；发车只能一次，之后状态转为进行中。检查点必须按赛道顺序打，编号不能跳，到达时间必须严格递增，每跑完一圈顺序回到第一个点，圈数达到配置值才算跑完。每个检查点记下当时的天气和路面，冲线时把实际用时加上罚时得到最终成绩；罚时按天气、轮胎、路面查配置表，再减车辆补偿，最低为零。中途换天气只影响之后打的检查点。排行榜完赛选手按最终成绩升序、同成绩按名字升序，未完赛状态记为 dnf 并排在后面；重复冲线报错，状态查询与内部数据隔离。未注册车手不能发车或打点，未知检查点编号要拒绝；天气只能在干地、雨天、暴风之间切换，非法值报错。最终成绩按整数秒累计，排行榜每行给出车手、车辆、轮胎、用时、罚时、最终成绩和状态。

## 运行方式
```bash
python -m pytest tests -q
```
