# GSB Bugfix Task
## 题面
宠物繁育的数值在测试服被玩家玩坏了。公母没校验，两只公狐狸也能生；不同物种混在一起照样出崽；自己和自己配种没有拦截。冷却时间只写了一个字段，实际没有比较，连续点繁育能一直生；父代和子代再配、兄妹再配也都能成功，血统表越滚越乱。基因组合没有固定规则，同一对父母每次生出来的等位基因顺序都不同，隐性纯合的父母生不出返祖变异；子代代数没有按父母较大代数加一，超过上限也不报错。pet_breeding.py 里的 PetBreeding 要把基因组合、表型判定、变异、代数、冷却和血统校验做成一条完整流程。每只宠物带物种、性别、三个基因的等位基因对、代数、父母和最近繁育时间；交配双方必须同物种、异性别、不是同一只，也不能有共同祖先。子代每个基因取父本第一条和母本第二条等位基因，若双方在该基因上四条等位基因全为隐性，子代首条基因突变为显性。表型按显性覆盖隐性判定，毛色输出 red 或 white，体型输出 large 或 small，速度输出 fast 或 slow，性别值用 m 和 f；战力等于十加二倍显性基因数，再加代数减一乘三。繁育要指定子代性别，成功后写回父母最近繁育时间并返回按序递增的子代编号，冷却期内、超过代数上限或血统冲突都拒绝。查询要给出每只宠物的基因、表型和战力，且不能共享内部字典。冷却按父母各自计算，任一方没冷却完都不能配；子代编号从一起按序递增，父母双方的最近繁育时间同时更新。未知宠物、非法性别和超过代数上限都要报错，查询里父母关系要能追溯，基因和表型分别给出。

## 运行方式
```bash
python -m pytest tests -q
```
